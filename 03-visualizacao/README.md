# 03 - Visualização

Escolher o gráfico certo e montar uma tela que responde antes de exigir esforço de quem olha.

## O que estudo aqui

- Qual gráfico para qual tipo de pergunta
- Hierarquia visual: o número mais importante tem que ser o primeiro que se enxerga
- Menos é mais: um dashboard com doze gráficos não responde nada
- Cor com função, não com enfeite
- Formatação condicional e uso consciente de KPI

## Pergunta que faço antes de cada gráfico

Que decisão alguém toma olhando isso? Se não tem resposta, o gráfico sai da tela.
