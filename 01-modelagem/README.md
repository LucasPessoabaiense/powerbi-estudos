# 01 - Modelagem

Dashboard ruim quase sempre é problema de modelo, não de gráfico. Por isso essa é a primeira pasta.

## O que estudo aqui

- Tabela fato e tabela dimensão: o que é cada uma e como decidir
- Star schema e por que ele ganha do modelo achatado
- Granularidade: qual é uma linha da minha tabela fato
- Relacionamentos, cardinalidade e direção do filtro
- Tabela calendário, que é obrigatória para time intelligence funcionar

## Erro comum que quero evitar

Jogar tudo numa tabela só porque funciona no começo. Funciona até o dia em que o relatório precisa de uma pergunta nova e o modelo não responde.
