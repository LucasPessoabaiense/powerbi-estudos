# 02 - DAX

Medidas, coluna calculada e as funções que uso de verdade.

## O que estudo aqui

- Medida versus coluna calculada: quando usar cada uma e por que medida quase sempre ganha
- Contexto de linha e contexto de filtro, que é o conceito central do DAX
- CALCULATE e como ele muda o contexto de filtro
- Time intelligence: acumulado no ano, mesmo período do ano anterior, média móvel
- Funções de iteração: SUMX, AVERAGEX e quando elas são necessárias

## Formato das anotações

Cada medida anotada vem com três coisas: o código, a pergunta de negócio que ela responde e a armadilha que ela tem.
