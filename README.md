# powerbi-estudos

Meus estudos de Power BI. Modelagem, DAX, visualização e dashboards de treino.

Uso Power BI no trabalho, mas aqui estudo a parte que quase ninguém estuda: o que sustenta o relatório por baixo.

## Como está organizado

| Pasta | Conteúdo |
|---|---|
| [01-modelagem](01-modelagem) | Fato, dimensão, star schema, relacionamentos e tabela calendário |
| [02-dax](02-dax) | Medidas, contexto de filtro, CALCULATE e time intelligence |
| [03-visualizacao](03-visualizacao) | Escolha de gráfico, hierarquia visual e design de tela |
| [dashboards](dashboards) | Dashboards de treino, com .pbix e print |

## Ordem que sigo

Modelagem primeiro, DAX depois, gráfico por último. Dashboard bonito com modelo ruim é só um problema mais difícil de enxergar.

## Sobre os dados

Nada de dado de cliente. Uso base pública ou dado gerado por mim.
