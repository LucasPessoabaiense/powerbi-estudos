# Dashboards

Dashboards de treino. São exercícios, não projetos. Projeto fechado ganha repositório próprio.

## Como guardo

Cada dashboard tem uma pasta com:

- O arquivo .pbix
- Um print em .png
- Um README curto dizendo de onde vieram os dados e o que o dashboard responde

## Atenção com os dados

Nada de dado de cliente aqui. Uso base pública ou dado gerado por mim. O que é do trabalho fica no trabalho.
